## 三、P2 问题处理

| # | 问题 | 处理方式 |
|---|------|---------|
| 1 | 工单列表无状态筛选 | 新增 tab：全部/待接单/已到件/已结算/已取消，前端客户端筛选 |
| 2 | 工单卡片信息密度低 | 4行紧凑：工单号+状态 / 客户+车型 / 应收+实收 / 时间 |
| 3 | 状态标签颜色混乱 | 草稿/接单=蓝；待接单/定件=橙；到件/结算=绿；取消=灰 |
| 4 | 库存无来源标签 | 官方=橙标签，第三方=蓝标签，兼容 partSource/source 两字段 |
| 5 | 库存无低库存提示 | 可用≤0 缺货（红）；可用≤3 低库存（橙）；纯 UI 提示 |
| 6 | 工作台模块空 | 问候卡片 + 快捷操作（按权限）+ 待办（清晰空状态） |
| 7 | 空状态文案 | 更自然的引导文案，带 emoji 图标 |
