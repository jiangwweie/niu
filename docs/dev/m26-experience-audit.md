## 5. P0 问题清单

> P0 = 阻塞客户使用 / 误导业务判断 / 可能导致错误数据

### P0-01 工作台「待办与提醒」永远显示静态空状态

- **模块**：小程序
- **页面**：`pages/dashboard/`
- **问题描述**：「待办与提醒」区域为硬编码静态内容，永远显示「当前无待办工单」，不加载任何真实数据
- **用户影响**：员工打开小程序首页看到「无待办」，误以为当前没有需要处理的工单，可能导致工单遗漏
- **严重级别**：P0
- **涉及文件**：`mini-program/src/pages/dashboard/index.wxml`
- **是否需要 backend**：是（需提供待办数量接口）
- **是否涉及数据风险**：否
- **建议修复方式**：对接真实工单数据，展示待维修/待交付等数量；或移除该区域，避免误导
- **验证方式**：有 DRAFT 或 REPAIRING 工单时，首页应显示对应数量

### P0-02 小程序退出登录无二次确认

- **模块**：小程序
- **页面**：`pages/mine/`
- **问题描述**：退出登录按钮无 `wx.showModal` 确认，点击即退出，清空所有本地登录态
- **用户影响**：误触退出后需重新登录，在外勤场景下浪费时间
- **严重级别**：P0
- **涉及文件**：`mini-program/src/pages/mine/index.ts`, `mini-program/src/pages/mine/index.wxml`
- **是否需要 backend**：否
- **是否涉及数据风险**：否
- **建议修复方式**：添加 `wx.showModal` 确认，文案示例：「确定退出登录？退出后需重新输入账号密码」
- **验证方式**：点击退出应弹出确认框，点取消不退出

### P0-03 clearAuth 存储键不匹配（可能残留旧用户数据）

- **模块**：小程序
- **页面**：全局（`stores/auth.ts`）
- **问题描述**：`clearAuth()` 执行 `wx.removeStorageSync('user')`，但 `storage.setUser()` 写入的键是 `auth_user`。两者不匹配，导致退出后 `auth_user` 中的旧用户数据可能未被清除
- **用户影响**：退出登录后重新登录，可能出现上一个用户的信息残留（在页面重新拉取 `/me` 前的短暂窗口期）
- **严重级别**：P0（潜在数据混淆风险）
- **涉及文件**：`mini-program/src/stores/auth.ts`, `mini-program/src/utils/storage.ts`
- **是否需要 backend**：否
- **是否涉及数据风险**：是（用户身份残留）
- **建议修复方式**：`clearAuth()` 中将 `wx.removeStorageSync('user')` 改为 `wx.removeStorageSync('auth_user')`，与 `storage.ts` 保持一致
- **验证方式**：退出登录后检查 `wx.getStorageSync('auth_user')` 是否返回空

### P0-04 管理端工单详情页「查看」导航链接断裂

- **模块**：管理端
- **页面**：`views/customer/index.vue`, `views/vehicle/index.vue`
- **问题描述**：客户详情和车辆详情中的「维修历史」表格，点击「查看」跳转 `/work-order?id=xxx`，但工单页面读取的参数是 `partId`（从 query 中），不是 `id`，导致跳转后工单详情无法正确加载
- **用户影响**：从客户/车辆详情点击查看工单，页面空白或加载失败
- **严重级别**：P0
- **涉及文件**：`admin-web/src/views/customer/index.vue`, `admin-web/src/views/vehicle/index.vue`
- **是否需要 backend**：否
- **是否涉及数据风险**：否
- **建议修复方式**：将导航参数从 `{ id: xxx }` 改为 `{ partId: xxx }` 或确认工单页面实际接收的参数名并统一
- **验证方式**：在客户详情的维修历史中点击「查看」，确认能正确跳转并加载工单详情

### 8.1 工单进度状态（ProgressStatus）

| 状态码 | 小程序文案 | 管理端文案 | 一致性 |
|--------|-----------|-----------|--------|

- 小程序：后端 `text` 优先 → 回退本地 map

## 12. 不建议本轮处理的事项

| 事项 | 原因 |
|------|------|
| 旧状态（PENDING_ACCEPT 等）显示差异 | 旧状态仅存在于试运行数据，清理后不再出现 |

| 管理端 mock 目录清理 | 不影响运行，可后续统一清理 |
| 配件/库存详情页开发 | 功能扩展类，非体验优化范畴 |
| 支付占位页（payment-placeholder）清理 | 无导航入口，不影响用户 |
| 我的页面 mock 用户切换器 | 已正确通过 API_MODE 隔离，不影响生产 |
| console.error 日志清理 | 有利于生产排查，建议保留 |
