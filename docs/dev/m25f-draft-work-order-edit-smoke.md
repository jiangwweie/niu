# M25F 草稿工单继续编辑热修复

## 1. 客户反馈问题

体验版中存在一笔工单处于 `DRAFT / 新建中`，应收金额为 `0.00`，无费用明细、无收款、无退款，但页面显示“无需收款”，且客户无法继续编辑。

## 2. 生产只读事实

- 当前生产 release：`20260604122843-fbd6a134e2b3`
- 当前活跃工单：`WO202606070001`
- 状态：`DRAFT`
- 应收：`0.00`
- 实收：`0.00`
- `no_charge_reason`：空
- 无费用明细
- 无收款记录
- 无退款记录
- 状态日志仅有 `CREATE -> DRAFT`

以上均来自只读查询；未修改生产数据。

## 3. 判断

这是前端入口和展示缺口，不是业务状态正常锁死。

`DRAFT` 工单应该允许继续编辑。后端已经有草稿基础信息更新接口和费用项增删改接口，并且后端只允许 `DRAFT` 普通编辑。`NO_CHARGE` 是应收为 0、实收为 0 时的派生收银状态，不代表空草稿已经确认免单。

## 4. 小程序修复

- 工单列表：`DRAFT` 且有 `WORK_ORDER_UPDATE` 权限时显示“编辑草稿”。
- 工单详情：`DRAFT` 且有 `WORK_ORDER_UPDATE` 权限时显示“继续编辑”。
- 创建/编辑页：
  - 无 `workOrderId` 时创建新草稿。
  - 有 `workOrderId` 时加载已有草稿详情。
  - 保存基础信息时调用当前草稿更新接口，不重复创建工单。
  - 费用明细继续复用已有新增、修改、删除接口。
- 草稿阶段收银展示：
  - 空草稿显示“待录入费用”。
  - 已有费用但仍未提交的草稿显示“草稿未提交”。
  - 不再把空草稿直接展示为“无需收款”。

## 5. 管理端修复

- 工单列表：`DRAFT` 且有 `WORK_ORDER_UPDATE` 权限时显示“编辑草稿”。
- 工单详情：`DRAFT` 且有 `WORK_ORDER_UPDATE` 权限时显示“编辑草稿”。
- 编辑弹窗支持维护草稿基础信息：

- 草稿阶段不再把空草稿展示为“无需收款”。
