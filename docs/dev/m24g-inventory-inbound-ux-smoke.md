# M24G 配件入库交互修复 Smoke

## 原问题

管理端库存管理页顶部“配件入库”按钮点击后只提示“请先在列表中选择配件进行入库”，用户必须先找到库存列表中的某一行才能打开入库弹窗。对门店员工来说，按钮语义应是直接进入入库流程。

## 修复后的入口

### 入口 A：顶部“配件入库”

1. 打开 `admin-web` 的“库存管理”页。
2. 点击顶部“配件入库”。
3. 系统直接打开入库弹窗。
4. 在弹窗“配件”下拉框中搜索并选择已有配件。
5. 填写入库数量、单位成本、入库原因、备注。
6. 点击“确认入库”。
7. 入库成功后弹窗关闭，并刷新库存台账列表。

配件下拉框复用现有配件列表接口，支持按配件名称、配件编码、官方品号搜索。

### 入口 B：行内“入库”

1. 打开“库存管理”页。
2. 在库存台账列表中找到目标配件。
3. 点击该行“入库”。
4. 系统打开同一个入库弹窗，并自动带入当前行的 `partId`。
5. 配件字段只读，避免误把库存记录 ID 当成配件 ID。
6. 填写入库数量、单位成本、入库原因、备注。
7. 点击“确认入库”。
8. 入库成功后弹窗关闭，并刷新库存台账列表。

## 提示文案

- 未选择配件提交时提示：“请选择要入库的配件”。
- 如果没有任何可入库配件数据，弹窗提示：“暂无配件，请先新增配件后再入库”。
- 在已有配件管理路由可用时，提示内提供“去新增配件”入口。
