# 小牛电动官方授权店两轮车维修售后库存管理系统需求文档（PRD V2）

## 1. 项目概述
本系统面向小牛电动官方授权售后门店，同时兼容第三方维修业务。系统目标是实现维修工单、库存管理、财务账目、官方售后、支付结算、报销台账的一体化管理。

## 2. 系统目标
1. 规范维修工单流程
2. 实现配件扫码/手动入库
3. 支持工单临时新增配件并入库
4. 实现库存实时查询及预占
5. 实现支付、退款与结算管理
6. 支持官方售后手动结算录入
7. 支持报销台账及运营成本记录
8. 财务报表及 Excel 导出
9. 支持多角色、多门店扩展能力

## 3. 系统形态
### 微信小程序（员工使用）：
- 创建工单
- 查询库存
- 扫码或手动入库
- 工单处理
- 客户结算
- 报销提交

### 网页管理端：
- 财务报表查看
- 库存管理与盘点
- 权限管理
- 报销确认
- Excel 导出

## 4. 当前 MVP 范围
### 启用功能：
- 单门店
- 官方售后
- 第三方维修
- 配件入库（扫码/手动）
- 工单系统（含临时配件入库）
- 支付、退款与结算管理
- 报销台账
- 库存调整
- 财务统计及报表导出

### 不做功能：
- 客户端小程序
- 员工提成
- 客户签字
- 图片上传
- 自动采购或同步官方系统
- 多门店运营
- 自动打款

## 5. 权限系统
采用“角色 + 权限点”设计，避免写死。
当前默认角色：
- 超级管理员
- 门店管理员
- 财务
- 维修员 / 前台

权限功能包括：
- 配件管理
- 工单管理
- 财务报表
- 报销确认
- 库存调整

## 6. 工单系统
### 订单状态：
1. 待接单
2. 已接单
3. 已定件
4. 已到件
5. 已结算
6. 已取消

### 工单字段：
- 工单编号（日期 + 序号）
- 客户姓名、联系方式
- 车型、车架号（维修历史绑定）
- 电池号
- 维修项目
- 使用配件列表（支持临时入库）
- 人工费、其他费用
- 支付信息
- 官方售后订单号
- 备注

## 7. 配件与库存管理
### 配件来源：
- 官方配件
- 第三方配件（编码系统自动生成）

### 入库方式：
- 扫码录入品号
- 手动输入品号
- 工单临时新增配件，可直接入库并扣减使用数量

### 入库字段：
- 品号/型号
- 配件名称
- 数量（临时入库数量默认 = 本次工单使用数量）
- 成本价
- 条形码
- 入库时间
- 分类（可选）
- 库存位置备注

### 库存规则：
- 提交工单时占用预占库存
- 已结算后正式扣减库存
- 订单取消后释放预占或退回库存
- 库存流水必须记录操作人、操作时间和原因

### 库存盘点（MVP）：
- 简单数量加减
- 必须记录库存调整原因
- 授权账号可调整

## 8. 条形码
系统根据官方品号或第三方型号生成条形码，支持打印。工单临时入库和正常入库均可扫码识别。

## 9. 支付与结算
支持多次付款 and 混合付款，支付方式包括微信、支付宝、银联。

### 支付记录字段：
- 关联工单号
- 支付金额
- 支付方式
- 支付时间
- 收款人
- 备注

### 退款规则：
- 定金退款或其他退款必须生成退款记录
- 退款记录字段：退款金额、退款时间、方式、操作人、原因、备注

### 工单“已结算”条件：
- 实收金额 >= 应收金额

## 10. 官方售后订单
官方售后订单特殊规则：
- 手动录入官方结算金额
- 标记为官方结算
- 官方订单号备注
- 客户支付与官方结算分开统计
- 收入统计时区分官方结算和客户支付

## 11. 财务系统
统计收入：配件收入、人工费、其他收入、官方结算收入
成本：配件成本、报销成本
利润 = 收入 - 成本
报表：日报、月报、时间范围查询
支持 Excel 导出

## 12. 报销台账系统
员工可提交报销记录：
- 报销人、用途、金额、备注、提交时间
状态：待确认、已确认、已驳回/取消
老板确认后计入店铺运营成本
后续扩展预留审批流、自动打款、凭证上传、报销类型管理

## 13. 小程序登录与客户车辆绑定
### 员工小程序登录：
- 支持手机号登录
- 支持微信登录（可绑定手机号）

维修记录绑定车架号，方便查看历史维修和配件记录。

## 14. Excel 导出
支持导出工单列表、财务报表、利润报表、库存报表、报销台账

## 15. 多门店与扩展预留
MVP 仅单门店。系统底层预留门店ID，方便未来支持多门店、门店调拨、多门店汇总报表

## 16. 禁止写死项
以下内容禁止硬编码：
- 配件分类
- 支付方式
- 权限
- 工单状态
- 配件来源
- 门店
- 角色
必须使用配置化、字典表或可扩展结构

## 17. 技术架构建议
- 小程序：微信小程序 / Taro
- 后端：Java Spring Boot
- 数据库：MySQL
- 网页端：Vue3 + Element Plus

## 18. 开发优先级建议
1. 登录与权限
2. 配件库存及入库
3. 工单系统（含临时入库）
4. 支付与结算管理
5. 报销台账
6. 财务系统
7. 扫码入库
8. Excel 导出及报表
