# ChatGPT 常用 Prompt

本文件用于 Owner 和 ChatGPT 协作时快速生成任务卡、审查方案和分配 Codex / Claude。

## 1. 方案分析 Prompt

```text
你是本项目的架构与方案顾问。

项目：小牛电动官方授权店两轮车维修售后库存管理系统。
当前工作流：
- 我是 Owner，负责业务判断、范围控制、验收。
- ChatGPT 负责方案、架构、任务拆解、审查。
- Codex 负责核心模块、数据库、库存、支付、财务等高风险实现。
- Claude 负责简单实现、测试、文档和低风险修改。

现在我要分析这个需求/模块：

【粘贴需求】

请你输出：
1. 业务目标
2. 关键规则
3. 数据模型影响
4. 是否属于 MVP
5. 风险点
6. 应交给 Codex 还是 Claude
7. 推荐任务卡
```

## 2. Codex 任务卡生成 Prompt

```text
请基于以下目标，为 Codex 生成一张可执行任务卡。

目标：
【填写目标】

要求：
1. 中文为主
2. 明确业务目标
3. 明确涉及模块和表
4. 明确必须遵守的业务规则
5. 明确不做范围
6. 明确测试要求
7. 明确输出格式
8. 如果涉及库存/支付/财务，必须标记为高风险
```

## 3. Claude 任务卡生成 Prompt

```text
请基于以下目标，为 Claude 生成一张低风险任务卡。

目标：
【填写目标】

要求：
1. 只允许 Claude 做简单、可回滚、低风险修改
2. 明确允许修改范围
3. 明确禁止修改核心库存/支付/工单/财务逻辑
4. 明确验收标准
5. 明确输出格式
```

## 4. Codex 输出审查 Prompt

```text
下面是 Codex 的实现结果，请你从 Owner 视角审查。

审查重点：
1. 是否扩大 MVP 范围
2. 是否破坏库存规则
3. 是否破坏支付退款规则
4. 是否破坏官方结算和客户支付分离
5. 是否破坏财务口径
6. 是否缺少事务
7. 是否缺少测试
8. 是否可以进入下一步

Codex 输出：
【粘贴 Codex 输出】
```

## 5. Claude 输出审查 Prompt

```text
下面是 Claude 的实现结果，请你判断是否安全。

审查重点：
1. 是否只做了低风险范围
2. 是否误改核心业务逻辑
3. 是否改动过大
4. 是否测试足够
5. 是否可以合并
6. 是否需要转交 Codex

Claude 输出：
【粘贴 Claude 输出】
```

## 6. 验收清单生成 Prompt

```text
请为以下模块生成手工验收清单和自动化测试建议。

模块：
【填写模块】

要求：
1. 覆盖正常流程
2. 覆盖失败场景
3. 覆盖重复提交
4. 覆盖权限
5. 如果涉及金额，检查 BigDecimal 和精度
6. 如果涉及库存，检查流水和预占/释放/扣减
```
