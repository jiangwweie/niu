# 项目核心业务规则

本文件记录本项目不可破坏的核心规则。

## 1. 工单规则

### 1.1 工单状态

当前状态：

```text
待接单
已接单
已定件
已到件
已结算
已取消
```

状态禁止散落硬编码。应通过枚举 + 字典表或统一配置维护。

### 1.2 工单编号

建议规则：

```text
日期 + 当日序号
```

例如：

```text
WO202605100001
```

### 1.3 工单字段

工单至少包含：

- 工单编号
- 客户姓名
- 联系方式
- 车型
- 车架号
- 电池号
- 维修项目
- 使用配件列表
- 人工费
- 其他费用
- 支付信息
- 官方售后订单号
- 备注
- 门店 ID
- 创建人
- 创建时间
- 更新时间

### 1.4 工单和车架号

维修记录应绑定车架号，用于后续查询历史维修和配件记录。

## 2. 库存规则

### 2.1 库存基本原则

库存不是简单字段。

必须同时维护：

```text
actual_qty      实际库存
available_qty   可用库存
reserved_qty    预占库存
```

### 2.2 入库

入库必须：

- 增加实际库存
- 增加可用库存
- 生成库存流水
- 记录操作人
- 记录时间
- 记录来源
- 记录原因或备注

### 2.3 工单提交时预占库存

只有提交工单时才预占库存。

禁止在“把配件加入工单草稿”时立即预占。

提交工单：

```text
available_qty -= 使用数量
reserved_qty += 使用数量
生成库存预占流水
```

### 2.4 工单结算后扣减库存

工单已结算后正式扣减库存：

```text
reserved_qty -= 使用数量
actual_qty -= 使用数量
生成库存消耗流水
```

### 2.5 工单取消释放库存

工单取消时：

```text
reserved_qty -= 使用数量
available_qty += 使用数量
生成库存释放流水
```

### 2.6 库存调整

库存调整必须：

- 只有授权账号可操作
- 必须填写调整原因
- 必须生成库存流水
- 不允许无记录直接改库存

### 2.7 临时配件

工单临时新增配件必须进入统一配件和库存体系。

禁止为临时配件单独写一套孤立逻辑。

临时入库数量默认等于本次工单使用数量。

## 3. 配件规则

### 3.1 配件来源

配件来源：

```text
官方配件
第三方配件
```

禁止硬编码在多个地方。

### 3.2 官方配件

官方配件允许录入官方品号。

### 3.3 第三方配件

第三方配件编码由系统自动生成。

### 3.4 条形码

系统根据官方品号或第三方型号/编码生成条形码。

工单临时入库和正常入库均应支持扫码识别。

## 4. 支付与退款规则

### 4.1 支付记录

支付必须是明细表，不得只存在工单字段中。

支付记录至少包含：

- 关联工单号
- 支付金额
- 支付方式
- 支付时间
- 收款人
- 备注

### 4.2 多次付款

一个工单允许多次付款。

### 4.3 混合付款

一个工单允许多种支付方式混合付款。

### 4.4 退款

定金退款或其他退款必须生成退款记录。

退款记录至少包含：

- 关联工单号
- 退款金额
- 退款方式
- 退款时间
- 操作人
- 原因
- 备注

### 4.5 已结算条件

工单已结算条件：

```text
实收金额 >= 应收金额
```

其中：

```text
实收金额 = 支付总额 - 退款总额
应收金额 = 配件销售金额 + 人工费 + 其他费用
```

## 5. 官方售后规则

官方售后必须支持：

- 手动录入官方结算金额
- 标记为官方结算
- 记录官方售后订单号
- 客户支付和官方结算分开统计
- 收入统计时区分官方结算和客户支付

禁止把官方结算金额当作客户支付金额。

## 6. 报销规则

### 6.1 报销字段

报销记录至少包含：

- 报销人
- 用途
- 金额
- 备注
- 提交时间
- 状态
- 确认人
- 确认时间

### 6.2 报销状态

状态：

```text
待确认
已确认
已驳回/取消
```

### 6.3 报销入账

只有老板确认后的报销记录才能计入店铺运营成本。

待确认和已驳回/取消的报销不得计入成本。

## 7. 财务规则

### 7.1 收入

收入包括：

```text
配件收入
人工费
其他收入
官方结算收入
```

### 7.2 成本

成本包括：

```text
配件成本
报销成本
```

### 7.3 利润

```text
利润 = 收入 - 成本
```

### 7.4 财务统计

客户支付与官方结算必须分开统计。

财务报表应支持：

- 日报
- 月报
- 时间范围查询
- Excel 导出

## 8. 禁止硬编码项

以下内容禁止写死在业务代码里：

- 配件分类
- 支付方式
- 权限
- 工单状态
- 配件来源
- 门店
- 角色

MVP 可通过字典表和枚举统一管理。
