# 验收测试清单

本文件用于 Owner 手工验收和 AI 生成测试用例。

## 1. 登录与权限

- [ ] 员工可以手机号登录
- [ ] 员工可以微信登录
- [ ] 微信登录后可以绑定手机号
- [ ] 不同角色看到不同菜单
- [ ] 无权限用户不能访问受限接口
- [ ] 操作记录能记录操作人

## 2. 配件入库

- [ ] 可以新增官方配件
- [ ] 可以新增第三方配件
- [ ] 第三方配件编码由系统自动生成
- [ ] 可以扫码入库
- [ ] 可以手动输入品号入库
- [ ] 入库后实际库存增加
- [ ] 入库后可用库存增加
- [ ] 入库后生成库存流水
- [ ] 入库记录包含操作人、时间、数量、成本价

## 3. 库存查询

- [ ] 可以按品号查询
- [ ] 可以按名称查询
- [ ] 可以按条形码查询
- [ ] 可以查看实际库存
- [ ] 可以查看可用库存
- [ ] 可以查看预占库存
- [ ] 可以查看库存流水

## 4. 工单创建

- [ ] 可以创建工单
- [ ] 工单编号自动生成
- [ ] 可以填写客户姓名
- [ ] 可以填写联系方式
- [ ] 可以填写车型
- [ ] 可以填写车架号
- [ ] 可以填写电池号
- [ ] 可以填写维修项目
- [ ] 可以添加配件
- [ ] 可以填写人工费
- [ ] 可以填写其他费用
- [ ] 可以填写官方售后订单号
- [ ] 可以保存备注

## 5. 工单提交与库存预占

- [ ] 工单草稿添加配件时不预占库存
- [ ] 提交工单时预占库存
- [ ] 提交后可用库存减少
- [ ] 提交后预占库存增加
- [ ] 提交后生成库存预占流水
- [ ] 库存不足时不能提交
- [ ] 同一配件多工单预占时数量正确

## 6. 工单取消

- [ ] 未结算工单可以取消
- [ ] 取消后预占库存减少
- [ ] 取消后可用库存恢复
- [ ] 取消后生成库存释放流水
- [ ] 已结算工单不允许普通取消，需走退款/售后规则

## 7. 工单结算与库存扣减

- [ ] 实收不足时不能标记已结算
- [ ] 实收达到应收时可以标记已结算
- [ ] 结算后预占库存减少
- [ ] 结算后实际库存减少
- [ ] 结算后生成库存消耗流水
- [ ] 重复结算不会重复扣库存

## 8. 临时配件

- [ ] 工单中可以临时新增配件
- [ ] 临时配件可以填写数量
- [ ] 临时入库数量默认等于本次工单使用数量
- [ ] 临时配件进入配件主数据
- [ ] 临时入库生成库存流水
- [ ] 临时配件结算后正确扣减库存

## 9. 支付记录

- [ ] 一个工单可以添加一笔付款
- [ ] 一个工单可以添加多笔付款
- [ ] 一个工单可以混合微信、支付宝、银联付款
- [ ] 支付记录包含金额、方式、时间、收款人、备注
- [ ] 工单实收金额等于支付总额减退款总额
- [ ] 支付金额使用精确小数

## 10. 退款记录

- [ ] 可以为工单添加退款记录
- [ ] 定金退款必须生成退款记录
- [ ] 退款记录包含金额、方式、时间、操作人、原因、备注
- [ ] 退款后实收金额减少
- [ ] 退款不会直接删除原支付记录

## 11. 官方售后

- [ ] 工单可以填写官方售后订单号
- [ ] 可以手动录入官方结算金额
- [ ] 可以标记为官方结算
- [ ] 官方结算金额不计入客户支付
- [ ] 财务报表中客户支付和官方结算分开显示

## 12. 报销台账

- [ ] 员工可以提交报销
- [ ] 报销记录包含报销人、用途、金额、备注、提交时间
- [ ] 新报销状态为待确认
- [ ] 老板可以确认报销
- [ ] 老板可以驳回/取消报销
- [ ] 待确认报销不计入成本
- [ ] 已确认报销计入成本
- [ ] 已驳回/取消报销不计入成本

## 13. 财务报表

- [ ] 可以查看日报
- [ ] 可以查看月报
- [ ] 可以按时间范围查询
- [ ] 可以统计配件收入
- [ ] 可以统计人工费
- [ ] 可以统计其他收入
- [ ] 可以统计官方结算收入
- [ ] 可以统计配件成本
- [ ] 可以统计报销成本
- [ ] 利润 = 收入 - 成本
- [ ] 客户支付与官方结算分开展示

## 14. Excel 导出

- [ ] 可以导出工单列表
- [ ] 可以导出财务报表
- [ ] 可以导出利润报表
- [ ] 可以导出库存报表
- [ ] 可以导出报销台账
- [ ] 导出数据与页面查询条件一致

## 15. 字典与配置

- [ ] 支付方式不写死
- [ ] 工单状态不散落硬编码
- [ ] 配件来源可配置
- [ ] 配件分类可配置
- [ ] 权限点可配置
- [ ] 角色可配置
- [ ] 所有业务表包含 store_id 或具备门店扩展能力

## 16. 回归测试主链路

必须跑通：

```text
新增配件入库 10 个
  ↓
创建工单使用 2 个
  ↓
提交工单
  ↓
可用库存变 8，预占库存变 2
  ↓
添加客户付款
  ↓
实收达到应收
  ↓
结算工单
  ↓
实际库存变 8，预占库存变 0
  ↓
查看财务报表
  ↓
收入、成本、利润正确
```
